An HTTP server,
built from scratch.

C++98 and the POSIX socket API, no libraries. One thread and one poll() serve every client, every listening socket and every CGI pipe, and nothing ever waits for anyone.

C++98POSIX socketsnon-blocking I/OHTTP/1.1CGINGINX-style config
1thread, one poll() for every client and pipe
4,018lines of C++98 in src/ and includes/
12regression and unit test scripts
512clients served; the next ones get a clean 503
Where would you like to go?

Run it: make && ./webserv config/default.conf, then open http://127.0.0.1:8082/INTERACTIVE.html. Keys 1–7 switch tabs. Print the page for a PDF handout.
