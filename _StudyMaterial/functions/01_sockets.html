allowed functions — group 01

Making a socket exist

The seven calls that turn nothing into a listening endpoint a browser can connect to. Run in this order, once per host:port in your config.

socket<sys/socket.h>
int socket(int domain, int type, int protocol);
does
Creates an endpoint for communication and returns a file descriptor for it. Nothing is bound or connected yet — it is an unaddressed socket.
here
socket(AF_INET, SOCK_STREAM, 0) — IPv4, TCP. One per listen directive in your config.
watch
The fd it returns is just an int, like any other. Everything after this is configuring that int.
setsockopt<sys/socket.h>
int setsockopt(int fd, int level, int optname, const void *optval, socklen_t optlen);
does
Sets an option on a socket.
here
You need exactly one: SO_REUSEADDR. Without it, restarting your server after a crash fails with "Address already in use" for up to a couple of minutes while the old connections sit in TIME_WAIT.
watch
Set it before bind(), or it has no effect. Skipping this will waste hours of your life during testing.
bind<sys/socket.h>
int bind(int fd, const struct sockaddr *addr, socklen_t addrlen);
does
Assigns an address — an IP and a port — to the socket. This is the moment the socket claims 0.0.0.0:8080.
here
Fails if another process already holds that port. Two server blocks trying to bind the same host:port must be detected by you, not discovered at runtime.
watch
Takes struct sockaddr_in cast to struct sockaddr*. The port inside it must be in network byte order — see htons.
listen<sys/socket.h>
int listen(int fd, int backlog);
does
Marks the socket as passive: it will now accept incoming connections instead of making them.
here
Called once per listening socket, right after bind. After this the fd goes into your poll set and stays there for the life of the program.
watch
backlog is how many finished-but-not-yet-accepted connections the kernel queues for you. It is not a client limit; it is a burst buffer.
accept<sys/socket.h>
int accept(int fd, struct sockaddr *addr, socklen_t *addrlen);
does
Takes the first queued connection and returns a brand-new file descriptor for it. The listening fd is untouched and keeps listening.
here
Call it only when poll() reports the listening fd readable. The new fd is a fresh connection: give it a state object, a read buffer, a write buffer, and add it to the poll set.
watch
The single most misunderstood call in the project. The listening socket never carries request or response bytes — it is a factory that makes connection sockets.
getsockname<sys/socket.h>
int getsockname(int fd, struct sockaddr *addr, socklen_t *addrlen);
does
Asks a socket which local address it is actually bound to.
here
Useful when you bind to port 0 and let the kernel choose, or to report the real port at startup. Not required by the project.
connect<sys/socket.h>
int connect(int fd, const struct sockaddr *addr, socklen_t addrlen);
does
Makes an outgoing connection to a remote address — the client side of the handshake.
here
A server does not call this. It is on the allowed list so you can write your own test clients in C++ if you want to.

Anything you learn about these — a man-page detail that bit you, a flag you had to look up, a snippet that finally worked — belongs in this file, next to the function it explains.
