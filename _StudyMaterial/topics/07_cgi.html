topic 07 — the fossil

CGI, and what a "backend" actually is

Before frameworks, this was the dynamic web: the server runs a program and sends you whatever it prints. Understanding it is understanding what Django and Node abstracted away.

CGI has no library and no API. The server puts the request into environment variables, pipes the body to the child's standard input, runs an interpreter, and reads the answer from the child's standard output. That is the entire interface, unchanged since 1993.
